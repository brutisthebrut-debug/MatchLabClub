# North star: readiness-first, matching is the payoff

The one promise: **become genuinely relationship-ready, then get matched (AI-driven)
with people you'd never find on your own, near you.** Readiness leads; matching is
the reward.

**The reframe that makes everything cohere:** the "optimize your existing dating
apps" tools (profile audits, Signal Score, message coaching, bio/prompt rewrites,
quizzes) are NOT the headline. They do two jobs: (1) deliver immediate value so
people stick, and (2) gather signal so the machine learns who the person is. The
unifying line is **"the more the machine knows you, the better it matches you."**
Everything feeds one rising **Match Readiness** meter that gates matching.

**Why:** the founder explicitly rejected leading with app-optimization (it caused
the mixed messaging). But he also needs stickiness and data before matching can
work, so the optimization tools survive as the value + data-gathering layer, not
the headline. Matching with people you can't otherwise find is the real product.

**How to apply:**
- Stickiness levers: gamification (readiness climb, unlocks, streaks), sharing, the
  blog as a helper/top-of-funnel.
- Data gathering is both manual (screenshots, profile details, quiz answers) and via
  integrations (social, spending, calendar).
- Matching is radius-based (e.g. 25/35/45 mi). Inclusivity is core: all genders and
  orientations, inclusive by default, never a niche app.
- Founder tools must let the founder curate what is good/bad.
- When reorganizing, do NOT delete or orphan existing pages. Keep the heart and keep
  the work; everything stays reachable, just better organized.

**Long-term / NOT-YET (do not build unless asked):** invite-only "after dark" mode
for casual connection (separate vibe); AI date-idea + location suggestions within
both people's vicinity; full OAuth integrations.

**Decided trail (the marked path through the forest):**
1. Discover (anon): landing -> free Signal Check -> report -> save. One hero path.
2. Onboarding (first login, before dashboard): confirm goal -> seed short wellness
   baseline -> connect one signal source -> personalized Home.
3. Build: Home centered on one rising Match Readiness meter; wellness + connections
   are the two big levers; next-best-action guides.
4. Act: day-to-day tools (coach, prep, rewrites) all feed readiness, no dead ends.
5. Match: readiness unlocks the matching cohort (radius-based), the payoff.
Sidebar consolidated to a focused spine (Home, Readiness, Tools, Connections,
Matching, Account) with advanced tools behind progressive disclosure, all still
reachable.
